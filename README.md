# p_solicitante

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts

Usage: bun run index.ts [options]

Options:
  -i, --input \<file\>
  -f, --friendly
  -v, --verbose
  -h, --host \<host\>
  -p, --port \<port\>
  --help              display help for command
```

This project was created using `bun init` in bun v1.2.19. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
